# MCI – New Chapter Motion (Remotion)

15-second vertical LinkedIn motion (1080×1350, 30fps).

## Approved flow
1. A NEW CHAPTER
2. EMPLOYEE EXPERIENCE
3. PEOPLE × DATA × AI
4. Hamrah Aval (MCI) / Employee Experience Designer
5. Official MCI logo reveal + role + PEOPLE × DATA × AI

## Visual direction
- Warm cream + pistachio / sage palette
- Kinetic typography
- Organic line/shape motion
- No phone UI, no robot/AI clichés
- Silent by design
- The official `logo-mci-02.svg` supplied by the user is used directly.

## Run in Remotion
```bash
npm install
npm run start
```

Composition: `MciNewChapter`

Render:
```bash
npm run render
```

Output target:
`out/mci-new-chapter.mp4`

## Online workflow
Because this project has no external image/font dependency, it is suitable for importing into an online development environment such as StackBlitz after placing these files in a GitHub repository.
